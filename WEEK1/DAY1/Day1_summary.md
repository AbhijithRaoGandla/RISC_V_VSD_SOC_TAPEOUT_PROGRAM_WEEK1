# RTL Workshop - Day 1 Summary

This session introduces the fundamentals of RTL design using Verilog. It walks through creating Verilog modules, writing corresponding testbenches, and simulating designs using Icarus Verilog (`iverilog`) and `GTKWave`.

Additionally, the workshop covers basic logic synthesis using Yosys with the Sky130 standard cell library. It emphasizes how the same testbench can be reused to verify both RTL and synthesized gate-level netlists, helping learners understand the mapping from high-level RTL to gates.

## Key Tools Used

- Verilog
- Icarus Verilog (`iverilog`)
- GTKWave
- Yosys
- Sky130 PDK

## Concepts Covered

- RTL design & testbench creation
- Simulation & waveform viewing
- Logic synthesis
- Gate-level netlist generation
- Reuse of testbenches for pre- and post-synthesis validation
